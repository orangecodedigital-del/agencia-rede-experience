# Agência Rede Experience

Site React + Vite para a Agência Rede.

## Desenvolvimento

```bash
npm install
npm run dev
npm run build
```

## Cloudflare Pages

Framework Vite; build command `npm run build`; output directory `dist`.

## Antes da publicação definitiva

A marca circular no cabeçalho é uma representação tipográfica provisória; substituir pelo arquivo oficial autorizado. O mapa é ilustrativo, não cartográfico. Veículos parceiros, preços e disponibilidade dependem de confirmação da Agência Rede. O contato WhatsApp foi fornecido pelo usuário. Não há pagamentos ou contratações automáticas.
